# 1. Librerie Utilizzate
- **Document Database**: Potrei utilizzare un database NoSQL come MongoDB o Cosmos DB per memorizzare i dati dei prodotti, scelgo invece di utilizzare un DB relazionale come PostgreSQL, affiancato dalla libreria ** Marten **, che permette di utilizzare PostgreSQL come un document database, semplificando la gestione dei dati.
In questo modo riesco a sfruttare la potenza di PostgreSQL, mantenendo la flessibilità di un document database.
